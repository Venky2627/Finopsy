# Finopsy Security Checklist

- `[ ]` RLS enabled on profiles
- `[ ]` RLS enabled on transactions
- `[ ]` SELECT isolation tested
- `[ ]` INSERT isolation tested
- `[ ]` UPDATE isolation tested
- `[ ]` DELETE isolation tested
- `[ ]` Ownership cannot be changed
- `[ ]` Service-role key never exposed to frontend
- `[ ]` Auth user deletion cascades correctly
- `[ ]` No financial data exposed through logs
