# Product: Finopsy — Your Money. Autopsied.

Finopsy helps Indian students answer: “Where the hell did my money go?” V1 is a fast, mobile-first diagnostic experience, not a budgeting app.

Flow: landing → demo/upload/quick add → categorized transactions → dashboard → Money Autopsy → personality → optional roast → privacy-safe share card.

Non-negotiables: financial figures are deterministic; LLMs are only optional fallbacks for ambiguous categorization and flavor copy; do not require signup before showing value; do not collect banking credentials.
